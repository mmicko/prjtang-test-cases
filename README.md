# Project Tang Test Cases

Test cases to validate NextPnR implementation for Anlogic FPGAs and compare results with 
Tang Dinasty Place and Route tool

Before running build with `make` command make sure you have prjtang and nextpnr in PATH.
To additionally use Anlogic place and route tool set next environment variable:

```
export TD_TOOL=/opt/TD/bin/td
```
